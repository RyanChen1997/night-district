# 《夜游街区》验收指南

先在标题页点「开始游戏」。宿主仍为竖屏时，游戏会自动旋转画面和双指操作，不强制切换小红书 App 或系统方向。

## 本地运行与验证

- 入口：`app/index.html`。本地浏览器可直接打开，仅用于开发冒烟。打包范围仅为 `app/` 的内容，`index.html` 位于 ZIP 根目录。
- `node --test tests/*.test.js`（Node 18+）：以生产仿真核心、固定帧步与种子驱动；覆盖外环驾驶/倒车/换模式/登顶、夜市事件整条链、三项任务与收押重试、路口和长期车流、碰车去重、增援、输入取消、平台存档以及渲染降级。
- 打包时按[小红书小工具在线文档](https://miniapp-sandbox.xiaohongshu.com/minitool/doc)和创服上传页提供的规范进行校验。
- `CHROME_BIN=/path/to/chrome node tests/browser-smoke.cjs`：可选的本地 Chromium CDP 冒烟（macOS 默认路径为已安装的 Google Chrome），用本地文件与调试管道。检查禁用脚本的静态壳、横向标题页、320/375/430 px 宿主宽度、横竖宿主切换、开始点击解锁音频和切换音量、操作区双击防缩放、双指取消、抢车切换驾驶、击倒结算和恢复、暂停焦点，以及注入 context lost 后切换简图；临时截图和 profile 在 `/tmp/night-cdp.*`，不产生发布产物。它不是模拟器、真机或性能验收。

| 文件 | 作用 |
|---|---|
| `map.js`, `game.js` | 世界坐标、路网/楼层/碰撞；固定 60 Hz 仿真、车辆、路人、巡逻、任务 |
| `render.js` | WebGL 1 批次着色、相机与程序化几何；共享模拟状态的 Canvas 简图 |
| `platform.js` | SDK 版本与窗口快照、安全区去重、容器任务存档队列 |
| `input.js`, `main.js`, `ui.css` | 横向触点映射、键鼠辅助、开始页、HUD 与结算 |
| `audio.js` | 点开始后解锁，离线合成脚步、车门、引擎、鸣笛、撞击、出拳和结果音效；发射声是带短回响的一次性音效，无循环底噪 |

## 人工验收路线

**A — 从便利店到停车楼，不需要接任务。** 首次进入看短提示；轻推摇杆步行、推满跑，往前靠近青绿色车，点「上车」。把车驶到北外环向东，到夜市路口沿东外环向南，左上小地图可辅助辨认转向，之后沿南路向西、沿西路向北回出生区。跟随信号和车队，遇红灯提前刹；过弯先松油或减速。车速降到低速时「下车」才可用；继续按刹车可倒车。下车后到便利店东侧靠黄柱的小巷，沿小巷过中间街道，前往东南车库，走西侧楼梯至顶层。在开阔处测试靠近行人会被阻挡或侧向分开，低速车头接触时不会直接穿过，较快撞击有非血腥反馈。核对楼梯的高度逐级变化，车不能通过小巷；从车库南侧画有中线的坡道能连续驶上顶层，侧墙不能穿过去。外环长度约 432 米，耗时取决于红灯和交通。

**B — 夜市的事件、追踪与降星。** 开青绿车到东北夜市附近，在开阔的路边停好后下车。先拔枪，右侧空地拖动准星，朝空处点「发射」；看人群逃散、车流降速、目击后升星。再发射一次以触发车辆追踪；回到停好的车，上车开一小段，低速时弃车，观察巡逻员下车继续步追。也可把车停进夜市内部，观察巡逻车开到附近道路后派员走进夜市。可以绕街角，利用建筑挡住视野；看 HUD 从「巡逻车追踪」转为「失去视野 · 搜索中」，再从多星逐渐解除。警车靠近本身不会结算。二星以上靠近巡逻员会显示控制进度，持续被控制才会「已被逮捕」；多次受到有效还击、体力耗尽才会「已被击倒」。两种结果均停在结算页，点击「返回便利店」后才移动玩家。发射有弹数限制；驶入车内后拔枪/射击按钮消失。真机首次点「开始游戏」后，在静止处确认没有持续沙沙声，再试听步行、发动机和发射音效；可在暂停菜单手动开关声音，宿主未放行时不阻断游戏。

**C — v3 新操作和双击回归。** 去有红绿灯的路口，等 NPC 车辆停住，靠近车门侧面点「抢车」，核对司机离车跑开、通缉上升、油门出现。下车后仍能再次上这辆车。收枪后面对附近 NPC 点「出拳」（键盘 `R`），要有挥拳和踉跄反馈；背对或隔墙不能命中。分别快速连点出拳、拔枪、发射等右下角按钮，确认画面不放大或卡在局部，第二次点击仍能被游戏接收（具体动作有冷却）。沿途比对店面、不同屋顶和阳台、夜市篷顶、河岸灯以及停车楼的轮廓。

**可各自重跑的任务。** 黄方块表示可开始任务/当前目标，未靠近时不会显示开始按钮，同一时刻只追踪一项。

- **顺路送一单**：便利店门前接件，走到砂糖夜市摊位点「交给摊主」；走外环、支路或穿巷都行。
- **桥下的三幅涂鸦**：河岸任务点接单，从桥的北侧或南侧坡口走进蓝汐河岸步道；沿河水一侧观察入坡、桥影和出坡三段，足够靠近会自动记入。在桥面上方不会计入桥下涂鸦。
- **停车楼取车**：步行靠近顶层标记接单；提示了驾驶琥珀色车离开车位会升二星。失去追踪并清空通缉后将同一辆车开到河边集合点。先让警察追上体验任务失败，再回顶楼确认可以重新开始；其他已完成任务不丢。

## 平台边界和发布前复核

- 仅原生 Storage 9.46+ 保存已完成任务；版本未知、未注入、读写超时/失败不会改用网页存储。读到异常不覆盖；写入未获确认会提示当前局仍有效。窗口用同步启动快照及 9.49+ `getWindowInfo`；9.55+ 优先用有效胶囊矩形，否则取有效独立按钮，并与安全区、左滑热区去重。
- 图形默认上限 DPR 1.5 / 2M 像素 / 100 draw calls / 100k 三角形；低档 1 / 1M / 50 / 50k；缺 WebGL、持续慢帧或 context 丢失可切换到简图继续同一局。简图是俯视视图，保留任务/高度/碰撞规则但不声称完整展现 3D 遮挡。警车使用有限路网，步行 NPC 使用短路径和近障碍避让，不模拟真实交通或战术。隐藏/暂停停仿真，回来不补算时间。
- **验收环境：** 创服平台模拟器、Android 真机扫码、iOS 真机扫码。使用同一份 ZIP 跑完上述路线和三项任务，分别记录首帧、持续性能、双指输入、安全区、前后台与 Storage 复开。单独记录旧 Chrome/WebView 61 兼容性和真机帧率。发布前按平台当期内容规则复核，非血腥不等于审核通过。
